01 / The brief

Five study surfaces share one model gateway.

The source combines generative study tasks with two local productivity tools. It keeps the implementation compact while showing distinct handling for free text, uploaded files, structured quiz output, downloads, and session-scoped state.

Explain

Shape a response around the learner

A topic, audience level, and selected learning features become a structured prompt. The returned explanation stays in Streamlit session state and can be downloaded as Markdown.

Summarize

Read text, code, or document uploads

The app accepts pasted content or PDF, text, Markdown, Python, and JSON files. PDF pages are read with pypdf before the extracted text is sent for summarization.

Test

Turn model output into a scored quiz

Gemini is asked for a JSON question array. A direct parser and regex fallback feed a Streamlit form, score calculation, and expandable answer explanations.

03 / Architecture

Four parts carry the study session.

The reviewed revision keeps the whole application in one Python entry point, with libraries supplying the interface, file extraction, environment loading, and model access.

Interface Streamlit tabs

Inputs, uploads, selectors, forms, downloads, scorecards, timers, and goal controls.

→
Processing Python helpers

Prompt assembly, PDF text extraction, UTF-8 reads, JSON parsing, scoring, and timer logic.

→
Generation Gemini gateway

Google's SDK is the primary path, with a REST request fallback when the SDK is unavailable.

→
Session Local app state

Generated text, quiz data, answers, timer status, and study goals remain in Streamlit session state.

04 / Constraints

The capstone boundary is explicit.

These limits come from the reviewed source. They do not imply learning outcomes, model accuracy, adoption, production scale, or client work.

Configure a key first

Model-backed features require a Gemini API key from an environment file or the password-style developer setting. The repository does not include a hosted model credential.

Keep state inside the session

Explanations, summaries, quiz answers, goals, and timer status use Streamlit session state. There is no account, database, or cross-session persistence layer.

Summarize a bounded excerpt

The summary prompt sends at most the first 15,000 characters of the extracted content to the model.

Extract text, not scanned images

PDF support calls pypdf page text extraction. The reviewed revision contains no OCR path for image-only pages.

Validate beyond parsing later

Quiz handling parses a JSON array directly or through a regex fallback. It does not validate every returned item against a formal schema before rendering its fields.

Add automated checks

The reviewed repository contains no application-level test suite, so its behavior is documented from the source rather than a passing automated test run.
