01 / Lead MERN proof

EcoTrace · TypeScript MERN

Follow one protected workflow from natural-language input to account-owned history.

A signed-in person describes an activity, receives bounded carbon estimates, saves the result, and later retrieves or deletes records that belong to the same account. The source shows React input handling, JWT middleware, Express controllers, a Gemini service boundary with deterministic fallback behavior, Mongoose persistence, and integration tests around the critical API paths.

The honest limit matters: EcoTrace produces estimates, not measured or certified environmental results. It demonstrates full-stack flow design and resilient integration behavior without claiming scientific validation.

02 / Commerce prototype

Bookify · JavaScript MERN

See where catalog, account, and cart state live.

Bookify loads a catalog, searches and filters it, connects signup and login endpoints, and keeps a duplicate-free cart in browser storage. That split makes state ownership easy to inspect: MongoDB holds books and users, while React context and local storage hold the prototype cart.

It is not a connected store. The reviewed version uses a local API base, browser-only auth state, no checkout or order flow, and no app-level tests. Those boundaries are part of the case study, not hidden behind a feature list.

03 / Practical AI tool input → normalize → gateway → fallback → useful output

AI Study Buddy · Streamlit + Gemini

Inspect a shared model gateway built for recoverable output.

AI Study Buddy turns text or documents into summaries, flashcards, quizzes, concept explanations, and downloadable study material. The defining decision is to normalize inputs before they reach one Gemini gateway, then recover structured quiz data and render useful fallbacks when model output is incomplete.

This is practical AI integration evidence, not a claim of model accuracy or production-scale usage. The page shows the shipped study workflow and the prototype constraints together.
