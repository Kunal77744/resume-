01 / TypeScript MERN Account-owned feedback

Authenticated activity-to-history loop

Turn one activity note into account-owned feedback.

EcoTrace accepts a plain-language activity description, requests a three-category JSON emissions breakdown from Gemini, clamps negative category values to zero, and stores the estimate against the authenticated account.

The same record returns through history and dashboard totals, with deletion scoped to its owner. Integration tests cover authentication, validation, calculation, history, and deletion while replacing the external AI call.

GitHub's public contributor graph attributes 23 repository commits to Kunal77744.

02 / JavaScript MERN Browser-held cart state

Source-observed catalog-to-cart loop

Trace one title from catalog search to browser storage.

The Bookify source requests the full book collection from a localhost Express API, filters book names and titles without case sensitivity, separates a free-book shelf, and writes cart changes to browser storage. The cart ignores another add for a book ID already present, supports removal, and calculates a total.

React routes and contexts define the interface and browser state. Express controllers and Mongoose models define book retrieval plus signup and login behavior.

Source-observed prototype only. There is no connected public store, server-validated session, checkout handler, or app-level test suite. The reviewed login controller reads a saved password before checking that its email lookup returned a user. Its single public commit does not establish contribution share, team size, or sole ownership.

03 / Python + Streamlit

One shared AI gateway

AI study flows and local focus tools

Put three model-backed study flows behind one gateway.

AI Study Buddy is a Streamlit capstone with five tabs for topic explanations, document summaries, generated quizzes, focus planning, and architecture notes. The first three tasks build specific prompts for Gemini. Summaries accept pasted text or supported document files.

One shared helper handles model access, retries with Gemini 1.5 Flash after a failed first SDK request, and uses a REST request if the SDK is unavailable. Quiz output gets direct JSON parsing plus a recovery path when extra text surrounds the question array. The interface can export generated study material and retains quiz scores, answer explanations, focus timers, and goals for the active session.

Model-backed features require a Gemini key. State lasts for the active Streamlit session, image-only PDFs have no OCR path, and the reviewed repository has no app-level tests. Its public history attributes four commits to Kunal77744 without establishing team size or sole ownership.
